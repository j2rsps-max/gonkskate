# GonkSkate Windows downloads

Latest milestone: **v0.7.0 — GonkSkate Hub**.

[Download the full v0.7.0 Windows ZIP](https://raw.githubusercontent.com/j2rsps-max/gonkskate/downloads/GonkSkate-v0.7.0-Windows-Playable-Full-Package.zip)

Extract the ZIP into a writable folder and double-click **GONKSKATE.cmd**.
Python 3 with Tkinter is required. Godot and both native x64 executables are included.

1. Run milestone check.
2. Find your installed Skate3Recomp or browse to skate3.exe.
3. Capture Skate area and test: enter a level, stop on flat ground, F10 once,
   wait for disk activity, then quit Skate normally. Keep several GB free.
4. Try THUG skating on that area. Close with Escape.
5. Return logs/GonkSkate-milestone-results-*.zip. Captures/ISO/world geometry stay local.

The hub saves your game path and local map library. Authentic THUG runs on
captured render triangles in a separate test window. Live THUG control of Skate's
own player remains pending; captures have generic concrete and no original rails.
Read START_HERE.md and docs/V070_MILESTONE.md in the package.

Validation: source-format capture through real THUG spawn/ollie/landing/replay;
full Linux hub/controller workflow; Windows native check under Wine. The owner
previously validated v0.6.6 courtyard/controller gameplay on actual Windows.
The new Windows hub UI and a retail Skate capture need the next owner test.
